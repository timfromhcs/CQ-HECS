      What this shows
      non-claims
      
        
      Every number comes from the running engine. Waves are exhaustive x / not-x splits of the search space; refuted fronts are logged as DRAT lemmas, short nogoods are shared only after logging, and UNSAT is reported only when cqhecs.drat accepts the proof. Coverage is the exact fraction of the 2n assignments already refuted or decided. Worker threads share one Python interpreter, so more workers are not a speedup claim, and no run says anything about P vs NP or ETH.
