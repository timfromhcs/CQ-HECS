# CQ-HECS Classical Four-Path Architecture

## 1. System Architecture Overview

**CQ-HECS** is a strictly classical quantum emulation engine. It completely eliminates silent bond-dimension truncation ($\chi = 48$) and replaces heuristic approximations with a verified **Four-Path Classical Architecture**:

```mermaid
graph TD
    QC[Quantum Circuit / OpenQASM / Qiskit] --> CA[CircuitAnalyzer]
    CA -->|Pure Clifford (T-Count = 0)| PA[Path A: Stabilizer-Tableau]
    CA -->|Low T-Count (T <= 14)| PB[Path B: Stabilizer-Rank-Decomposition]
    CA -->|1D Cut Entanglement <= 32| PC[Path C: Unbounded MPS + NVMe-Offload]
    CA -->|High Entanglement & High T-Count| PD[Path D: Certified Sparse-Pauli-Dynamics]

    PA --> Res[SimulationResult]
    PB --> Res
    PC -->|Storage Budget Exceeded w/o Opt-in| PD
    PC -->|Exact within Memory| Res
    PD -->|Accumulated Error <= Tolerance| Res
    PD -->|Accumulated Error > Tolerance| Unres[Mark as 'unresolved=True' - Zero Guessing]
```

## 2. Formal Path Definitions & Mathematical Proofs

### Path A: Stabilizer Tableau (Aaronson-Gottesman 2004)
- **Target Circuit Class:** Pure Clifford circuits generated by $\{H, S, S^\dagger, X, Y, Z, CX, CZ, SWAP\}$.
- **Mathematical Invariant:**
  Every Clifford operator maps Pauli group elements $\mathcal{P}_n$ to single Pauli group elements under conjugation:
  $$U^\dagger P U = P' \in \mathcal{P}_n$$
- **Data Structure:** Binary symplectic tableau of dimension $(2N + 1) \times (2N + 1)$ maintaining $N$ destabilizers and $N$ stabilizers over $\mathbb{F}_2$.
- **Complexity:** $O(N)$ per 1-qubit Clifford gate, $O(N)$ per 2-qubit Clifford gate, $O(N^2)$ per measurement.
- **Error Guarantee:** $\epsilon = 0.0$ (Bit-Exact).

### Path B: Stabilizer Rank Decomposition (Bravyi-Smith-Smolin)
- **Target Circuit Class:** Clifford $+ T$ circuits with low $T$-count ($T \le 14$).
- **Mathematical Invariant:**
  Every non-Clifford rotation decomposes into an exact sum of stabilizer operators:
  $$T = \cos(\pi/8) I - i \sin(\pi/8) Z = c_0 I + c_1 Z$$
  $$R_Z(\theta) = \cos(\theta/2) I - i \sin(\theta/2) Z$$
- **Complexity:** $O(2^{\alpha T} \cdot \text{poly}(N))$ where $\alpha \approx 0.47$.
- **Error Guarantee:** **No deliberate approximation**: the branch expansion is
  algebraically exact, but amplitudes and branches are evaluated in IEEE-754
  `float64` (`numerical_mode = "float64-exact-decomposition"`). `error_bound =
  0.0` therefore means "nothing was deliberately truncated", **not** symbolic
  exactness or universal bitwise identity; finite-precision rounding is
  inherited from the float evaluation and is not certified away.

### Path C: Unbounded Matrix Product State + Storage Paging
- **Target Circuit Class:** Circuits with low-to-moderate 1D bipartite entanglement cuts.
- **Mathematical Invariant:**
  Statevector is represented as an open tensor chain:
  $$|\psi\rangle = \sum_{s_1, \dots, s_n} A_1^{[s_1]} A_2^{[s_2]} \cdots A_n^{[s_n]} |s_1 \dots s_n\rangle$$
  Two-site gate updates contract adjacent tensors and perform Singular Value Decomposition (SVD):
  $$M = U S V^\dagger$$
  The bond dimension $\chi$ expands to the full **numerical rank** of the two-site block. There is no artificial ceiling and no truncation budget.
- **Floating-Point Contract (important):**
  Rank selection keeps every singular value above a *relative roundoff floor*, $\sigma_i > 10^{-13}\,\sigma_{\max}$. This is a statement about IEEE-754 double precision, not a mathematical approximation: values below the floor are numerically indistinguishable from zero. The discarded mass is **measured** and reported as `discarded_spectral_mass_diagnostic`; it is never silently dropped. It is deliberately **not** reported as `numerical_error_bound`, because per-SVD discarded masses do not compose into a state-norm bound without a propagation analysis this backend does not perform, so `numerical_error_bound` stays `None`.
- **Memory Ceiling & Escalation:**
  When RAM allocation exceeds user budgets, site tensors page out to a private scratch directory. If total storage limits are reached, the allocation is refused **before** any state is mutated, leaving the chain coherent, and the result is `unresolved=True`. The router may then escalate to Path D.
- **Counts Limitation:**
  MPS-native sampling avoids materialising $2^n$ amplitudes and is allowed up to
  `MAX_SAMPLING_QUBITS` (500), bounded by the RAM budget and the
  `shots × qubits` batch ceiling. Above that routing ceiling the circuit is
  executed and reported, but **no counts are produced** — the backend reports
  the fact rather than returning a placeholder. Dense statevector conversion is
  a separate operation and is capped at `MAX_STATEVECTOR_QUBITS` (20).
- **Reported Guarantee:** `error_bound = 0.0` (no *deliberate approximation*), `numerical_error_bound = None` (no defensible propagated roundoff bound is derived; the measured `discarded_spectral_mass_diagnostic` is not presented as one), `sampling_error_bound` = Hoeffding bound on the finite-shot counts.

### Path D: Certified Classical Approximation (Sparse-Pauli-Dynamics)
- **Target Circuit Class:** Arbitrary quantum circuits exceeding exact memory/rank budgets.
- **Supported Output:**
  Path D produces **certified expectation values**, not a bitstring distribution. It reports single-qubit $\langle Z_q\rangle$ and parity $\langle Z_q Z_r\rangle$ observables; the parity terms are what carry multi-qubit correlation structure (a Bell state has all single-qubit marginals zero).
- **Mathematical Invariant (Heisenberg Operator Dynamics):**
  Observables evolve backwards in time under Heisenberg dynamics:
  $$O(t) = U^\dagger O U = \sum_{P \in \mathcal{P}_n} c_P P$$
  Single-qubit conjugation is applied via Pauli-basis matrices derived from the gate unitary, which keeps phase bookkeeping exact. CX, CZ and SWAP are conjugated by explicit Clifford rules. Any gate that cannot be conjugated exactly is **refused** rather than treated as the identity.
- **Provable Error Bound Certificate:**
  When term count exceeds budget $K$, terms with smallest $|c_P|$ are pruned into set $\mathcal{D}$:
  $$\Delta_{\text{trunc}} = \sum_{P \in \mathcal{D}} |c_P|$$
  By the triangle inequality and the operator norm property $\|P\|_\infty = 1$:
  $$|\langle \psi_0 | O_{\text{exact}} | \psi_0 \rangle - \langle \psi_0 | O_{\text{approx}} | \psi_0 \rangle| \le \sum_{P \in \mathcal{D}} |c_P| = \Delta_{\text{trunc}}$$
  This bound certifies **expectation values only**. It does not certify a sampled bitstring distribution. Result metadata records this explicitly via `error_bound_covers` / `error_bound_excludes`.
- **Joint Counts Are Opt-In:**
  Sampling each qubit independently from its own marginal is *not* a joint distribution — a Bell state would emerge uniform. Such counts are therefore disabled by default. A caller may pass `allow_uncertified_joint_counts=True`, which returns them labelled `counts_are_joint_distribution=False` and outside the certified bound.
- **Unresolved Threshold:**
  If the accumulated error bound $\Delta_{\text{total}} > \epsilon_{\text{tolerance}}$, the result is flagged with `unresolved=True` and no expectation values are returned. No guessing is permitted.

## 3. Theoretical Complexity Grounding (Principle: Grounding)

Classical simulation of arbitrary quantum circuits remains subject to fundamental computational complexity:
$$\text{BPP} \ne \text{BQP} \quad (\text{Standard Complexity Conjecture})$$

Path D does **not** claim to bypass this bound or simulate arbitrary quantum circuits in polynomial time. In the worst case (deep random quantum circuits with 2D/all-to-all connectivity), the number of significant Pauli terms grows exponentially with circuit depth. Path D guarantees **transparent, mathematically certified degradation** within known complexity limits.

## 4. Routing & Result Contracts

### Routing fails closed
- An unrecognised circuit input raises `UnsupportedCircuitInput` (an alias of
  `UnsupportedCircuitInputError`). The analyzer never defaults an unknown input
  to a path.
- A user-forced path is never silently rerouted. If the circuit uses a gate the
  forced path cannot execute, the router raises `UnsupportedCircuitError` naming
  the offending gate.
- Gate names, arity, parameter counts and per-path support come from
  `cqhecs/gate_manifest.py`; `PATH_CAPABILITIES` is derived from it. The
  analyzer's "supported" answer therefore implies execution by the selected
  path, or a refusal before execution.
- Composite gates (`u/u3/u2`, `sx/sxdg`, `cy`, `ch`, `cs/csdg`, `rzz/rxx/ryy`,
  `ccx/toffoli`, `ccz`, `cswap/fredkin`) have no kernel of their own.
  `parse_circuit` rewrites them through exact unitary identities in
  `cqhecs/gate_lowering.py` (global phase included) before analysis, so routing
  and resource counts reflect the decomposition.
- Parameterised gates are classified per angle: `cp`, `crz`, `rz`, `p` and `u1`
  are only Clifford at exact multiples of π/2, and `cp`/`cu1`/`crx`/`cry`/`crz`
  are Path C only. `reset`, mid-circuit measurement and classical conditions are
  refused before execution rather than routed as unitary gates.
- `auto` mode selects only a path that explicitly supports the circuit.
- Only specific capability failures (`StabilizerRankError`) trigger escalation.
  A programming error propagates instead of being misread as "try the next path".

### Result semantics
`SimulationResult` separates three independent error sources instead of
conflating them in a single `error_bound`:

| Field | Meaning |
| :--- | :--- |
| `error_bound` | **Deliberate approximation** (truncated Pauli terms, any opt-in truncation). `0.0` means nothing was deliberately approximated. |
| `numerical_error_bound` | **Floating-point roundoff**, measured where the backend can measure it (e.g. Path C's discarded singular-value mass). |
| `sampling_error_bound` | **Finite-shot sampling** error, a rigorous Hoeffding TV bound `sqrt(ln(2/delta)/(2*shots))`. |

`total_error_bound` sums them. A result therefore never claims zero error while
actually being a finite-shot estimate.

`state` is one of `EXACT`, `CERTIFIED`, `UNRESOLVED` or `FAILED`. `EXACT`
requires `exact=True` **and** `error_bound == 0.0`.

### Bitstring convention
Qiskit renders qubit 0 **rightmost**. Every path follows this, and the native
C++ engine's output (which renders qubit 0 leftmost) is normalised before being
returned. Classical bits are populated from the circuit's actual `measure`
mapping, so `measure_all()` circuits produce the same keys as Aer.
