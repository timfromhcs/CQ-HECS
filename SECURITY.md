# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :---: |
| 4.5.x | Yes |
| < 4.5 | No |

## Reporting a Vulnerability

If you discover a security vulnerability or algorithmic integrity flaw in CQ-HECS, please do NOT create a public issue.
Send a responsible disclosure report directly to: **timfromhcs@gmail.com** with the subject [SECURITY] CQ-HECS Vulnerability Report.

Please include:
1. Exact commit hash or release version (cq_hecs --version).
2. Operating system and hardware environment (GPU, VRAM, Driver version).
3. Minimal reproducible proof-of-concept (QASM circuit, DIMACS CNF formula, or ARX vector).
4. Potential security or numerical divergence impact.

We endeavor to review and respond to valid responsible disclosures within 48 business hours.
